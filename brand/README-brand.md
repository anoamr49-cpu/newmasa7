# هوية «مقياس» البصرية

| الملف | الاستخدام |
|---|---|
| `play_icon_512.png` | أيقونة متجر Google Play (512×512، بدون شفافية) |
| `icon_1024.png` | الأيقونة الرئيسية بدقة عالية (تُستخدم كمرجع تصميمي) |
| `icon_mark_transparent.png` | العلامة بشفافية (للاستخدام فوق أي خلفية) |
| `logo_horizontal.png` | الشعار الأفقي الكامل (العلامة + الاسم العربي + MIQYAS) |

## الألوان الرسمية
- الكحلي الغامق: `#0A122C` (الخلفية الأساسية)
- الأزرق الملكي: `#0084FF` (الأزرار الأساسية)
- السماوي: `#00E5FF` (العناوين والقيم)
- الكهرماني: `#FFC024` (التنبيهات والتمييز)

## دلالات العلامة
- حرف **M** مبني من مسطرة قياس مطوية + حاجز (Caliper) = دقة القياس والحساب.
- فقاعة الميزان الكهرمانية = ضبط الأفقية والمناسيب.
- التوتال ستيشن أسفل اليمين = المساحة الميدانية.
- خطوط المخطط السماوية = الرسم الهندسي والرفع.
