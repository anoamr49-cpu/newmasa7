# مساح ومقاول — تطبيق amrtools

تطبيق Flutter عربي (RTL) مستوحى من منصة amrtools.pro، ومجهز بالحزمة:
`com.iraqia.amr`

## الموجود داخل النسخة
- حسبة أوضة/صالة: مباني + خرسانة + محارة + سيراميك/دهانات بشكل إرشادي.
- حسبة سور بالبلوك الأبيض.
- محارة الواجهات.
- محاكي الميول والقطاعات.
- محول وحدات هندسي ومساحي.
- حساب وزن الحديد النظري: kg/m = d² / 162.
- سجل آخر الحسابات محلياً على الهاتف.
- نسخ/مشاركة التقرير.
- Dark/Light mode.
- هوية جديدة وLogo مخصص.
- واجهة عربية RTL.

## ملاحظة الدقة
المعادلات المنشورة في الموقع تشمل:
الحجم = الطول × العرض × الارتفاع
وزن الحديد لكل متر = القطر² / 162
المساحة الصافية = (المحيط × الارتفاع) - الفتحات + نسبة الهالك

الأسعار والمصنعية ليست مثبتة داخل التطبيق لأنها تتغير حسب السوق؛ لذلك التطبيق يركز على الكميات والحسابات.

## الإصدار الموسع
- هوية التطبيق أصبحت: **مساح ومقاول**.
- أضيف GPS للرفع المبدئي: قراءة الموقع، حفظ النقاط، المسافات، ومساحة مضلع تقريبية.
- أضيف مساعد هندسي داخل التطبيق.
- أضيف قسم سيرة ذاتية للمهندس عمرو جمال عوض.
- تم الحفاظ على `com.iraqia.amr`.

### تنبيه الدقة المساحية
دقة GPS الهاتف تتأثر بالسماء والمباني والعتاد. لا تستخدمه كبديل عن RTK/Total Station في أعمال التوقيع أو الحدود القانونية.
