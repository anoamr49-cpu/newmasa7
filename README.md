# مقياس | أدوات المساح والمقاول

تطبيق Android أصلي مكتوب بـ Kotlin، بدون مكتبات UI خارجية، مخصص للحسابات الهندسية والمساحية اليومية.

**Package:** `com.iraqia.amr`  
**Name:** مقياس — Miqyas  
**Version:** 1.1.x  
**Target/Compile SDK:** Android 16 / API 36

## ما تم تحسينه في هذه النسخة

- إعادة تصميم كاملة للواجهات: الرئيسية، القوائم، الحاسبات، GPS، المساعد، الوحدات، السجل، النقاط، الأسعار، و"عن المهندس".
- الرئيسية بنفس روح التصميم المرجعي: هوية واضحة، بانر هادئ، شبكة 2×2، وأدوات سريعة منفصلة.
- كروت موحّدة، رموز خطية بسيطة بدلاً من الإيموجي، ترويسات نظيفة، وBottom Navigation هادئ.
- استخدام شعار مقياس الحقيقي داخل التطبيق بدلاً من حرف M، مع الحفاظ على الأداء بدون مكتبات UI خارجية.
- دعم أفضل لـ Android 15/16 وواجهة edge-to-edge مع معالجة system insets.
- تحسين حسابات WGS-84: مسافات جيوديسية بطريقة Vincenty مع fallback، ومساحة المضلع عبر UTM عند بقاء النقاط في نفس المنطقة.
- تصحيح حساب المناسيب Rise & Fall لعرض منسوب كل نقطة بدلاً من تقريب المنسوب الأخير.
- إصلاح حساب الأسمنت في صبة السقف ليحسب الشكاير من الكيلوغرامات بدلاً من تقريب طن كامل.
- إصلاح تكلفة الطوب لتستخدم سعر الألف طوبة المحفوظ فعلياً.
- إزالة نتائج مشتقة غير دقيقة من حاسبات الحفر والسيراميك.
- تمييز الحاسبات الإنشائية والكميات بأنها **تقديرية**، بينما أدوات الإحداثيات والمساحة والحسابات الجيوديسية تُعرض كحسابات هندسية/مساحية تعتمد على دقة المدخلات وGNSS.

> ملاحظة مهمة: حاسبات كميات الخرسانة والحديد والطوب والتشطيبات تعتمد معاملات تقديرية ما لم تدخل بيانات التصميم والمواصفات الفعلية. لا تعتبر بديلاً عن اللوحات الإنشائية أو الحصر التنفيذي.

## البناء محلياً

يتطلب JDK 17.

```bash
./gradlew assembleDebug
```

ولبناء Release غير موقّع محلياً:

```bash
./gradlew bundleRelease
```

## البناء على Codemagic

الملف `codemagic.yaml` موجود في جذر المشروع ومجهز لبناء **AAB + APK**.

1. ارفع المشروع إلى GitHub.
2. في Codemagic أضف المستودع واختر Native Android.
3. في **Code signing identities → Android keystores** ارفع ملف التوقيع الخاص بك، واستخدم مرجعاً باسم `miqyas_release` أو عدّل الاسم في `codemagic.yaml`.
4. ابدأ workflow باسم `android-release`.
5. Codemagic سيحقن `CM_KEYSTORE_PATH` و`CM_KEYSTORE_PASSWORD` و`CM_KEY_ALIAS` و`CM_KEY_PASSWORD` أثناء البناء.

**لا ترفع ملف `.jks` أو كلمات مرور التوقيع إلى GitHub.**

## متطلبات Google Play الحالية

التطبيق مضبوط على `compileSdk = 36` و`targetSdk = 36` لأن Google Play يشترط، اعتباراً من 31 أغسطس 2026، أن تستهدف التطبيقات الجديدة والتحديثات Android 16 / API 36 أو أعلى.
